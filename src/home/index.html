Pandion

Use case

Where should the next drop go?

Two aircraft, three ignitions and one hour. Every order is given with information that arrives late. The same fire is run under a learned policy, a downwind rule and no aircraft, so what changes is only the decision.

Research prototype, not an operational tool.

Pulse

Use case

Which tool will cut me off first?

You are in the middle of a task with Codex, Claude Code and Gemini open. Each has its own limits, reported in its own place. Pulse keeps what is left of all three in the menu bar, so you can switch before you hit a wall.

Usage figures are demo data.

LOSSIA

Use case

Where do we send maintenance first?

It is the start of the shift on a 91-station engine line, and every Excel file points to a different machine. LOSSIA estimates the engines lost per day at each station, including the waits it causes in its neighbours, and gives everyone the same list.

Hypotheses pending validation on the plant floor. The app is in Spanish.

Halfline

Use case

What do the odds really say?

Fiorentina v Juventus. The three prices add up to 106.6%, so none of them is a probability yet. Halfline strips the margin, sets its own model next to the market and then checks both on matches they never saw.

Work in progress. The app is in Spanish.
